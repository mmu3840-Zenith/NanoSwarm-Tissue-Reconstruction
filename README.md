# NanoSwarm Tissue Reconstruction

This project simulates nanoswarm-based tissue reconstruction mechanisms.

## Structure
- paper/ → LaTeX research paper
- simulations/ → Experimental simulations
- results/ → Output graphs, logs, and tables
- visuals/ → Diagrams and system illustrations

## Experiments
- experiment_1_scalability: tests system performance under increasing load
- experiment_2_failure: tests robustness under failure conditions
