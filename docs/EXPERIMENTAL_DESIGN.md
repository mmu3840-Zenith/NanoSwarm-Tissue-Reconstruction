# Experimental Design

Population sizes: 10, 25, 50, 100, 200.

Damage densities: 0.05, 0.10, 0.15, 0.20.

Failure probabilities: 0.0, 0.005, 0.02.

Policies: greedy, pheromone, dqn, hybrid.

Use matched seeds and shared initial conditions. Quick runs are
software smoke tests and must not be presented as final evidence.
